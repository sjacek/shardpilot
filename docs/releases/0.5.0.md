## Run the tests you choose

Use a consumer-owned YAML manifest to select a smoke suite or another chosen class subset,
then run it on one node or split it across several CI jobs. Both adapters validate the request
against the full eligible suite before planning. Empty, duplicate, unknown or malformed requests
fail rather than silently changing the suite. Eligible nested/outer family members stay together.

Each named selection has separate native reports, YAML snapshots, selection diagnostics and
coverage JSON/HTML. The cohort identity binds manifest bytes, eligibility, history and shard count;
aggregation rejects mismatched jobs. Matching class manifests still does not prove test methods
ran or passed: retain native results and require every shard.

Selection is opt-in. Without it, existing sharding, history refresh, worker controls and full-suite
report paths remain unchanged. See the [selection reference](../test-selection.md) for filters,
family expansion, report paths and native Maven runner wiring.

## Upgrade and examples

Change the Gradle plugin version:

```groovy
plugins {
    id 'io.github.sjacek.shardpilot' version '0.5.0'
}
```

Kotlin DSL uses `id("io.github.sjacek.shardpilot") version "0.5.0"`. Maven consumers update
`io.github.sjacek:shardpilot-maven-plugin` to `0.5.0` in their existing build plugin configuration.
No consumer dependency or schema migration is required.

Try the Docker-free selection examples using this checkout:

- [Gradle Jupiter](https://github.com/sjacek/shardpilot/blob/main/examples/gradle/junit-jupiter/test-selection/README.md): local composite
  resolution, complete eligibility, selected-suite reports and two-node aggregation.
- [Maven Jupiter](https://github.com/sjacek/shardpilot/blob/main/examples/maven/test-selection/README.md): locally installed adapter,
  native Surefire exclusions, selected-suite XML and two-node aggregation. Maven Invoker checks
  the actual example and native identities as part of producer verification.

Existing [Gradle](https://github.com/sjacek/shardpilot/blob/main/examples/gradle/README.md) and [Maven examples](https://github.com/sjacek/shardpilot/blob/main/examples/maven/README.md)
exercise this checkout. Do not replace maintained history or change a manifest while
nodes execute; all jobs in a cohort need identical version, manifest, eligibility, history and count.
Native framework filters and the decision to use a short suite remain consumer responsibilities.
